# Free & Private Captions

Free automatic subtitles, local transcription and editable karaoke captions.

**[Open Captions](https://freeandprivate.top/captions/) · [Website](https://freeandprivate.top/) · [Practical guides](https://freeandprivate.top/en/guides/)**

![Actual Captions editor with English interface and a demonstration recording](https://freeandprivate.top/assets/guides/editor-en.webp)

## What you can do

- Generate captions from speech in video or audio on your device.
- Correct recognised text and adjust timing on the timeline.
- Style captions and highlight spoken words with karaoke.
- Export SRT for text and timestamps, or render captions into video using MP4 beta.
- Keep editable projects locally and export project backups.

## Try a real project

[Open the worked example](https://freeandprivate.top/en/examples/) to download
the short source recording, actual SRT output, karaoke MP4 and a restorable TAR
project. Restore creates a new local project, so you can explore editing without
running recognition again. The page explains every file and the checks performed.

The recording is synthetic English speech created locally from original text.
Recognition for this example used the optional connected Windows/NVIDIA module;
it is not a browser-only speed or general accuracy benchmark. MP4 output from
build 87 was independently decoded: 454 video frames with preserved presentation
clocks and matching decoded audio. The backup preserves the original media bytes.
All six page languages use this same clearly labelled English recording.

Recognition supports 28 recording languages. The interface is available in English,
Polish, German, Spanish, French and Italian. Choosing a recording language does
not translate the subtitles.

## Local processing and privacy

Your recording and recognised text are not sent to cloud transcription or cloud
export services. Browser processing uses WebGPU where supported, with WebAssembly
CPU as a fallback. An already installed and approved Windows/NVIDIA module can
provide optional local acceleration.

The website, fonts and speech models may need internet access. Their providers
may receive connection metadata, including IP addresses. Local processing is not
a promise of complete anonymity or fully offline operation.

## Practical limits

Media compatibility depends on the browser and codecs. Performance depends on
hardware, memory and recording length. Always review recognition and timing,
especially with noise, music, names or fast speech.

MP4 export is beta: up to 1920 px on the longer side, 512 MB output, no HDR.
SRT does not retain colours, fonts or karaoke animation. Projects do not sync
automatically between devices. Back up a project before clearing browser data.
